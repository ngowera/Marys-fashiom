# Mary’s Fashion

Mary’s Fashion is a fashion marketplace in Malawi, with a companion inventory app.

The logo direction is a rounded, looping thread mark that subtly suggests an n or a stitch. It uses forest green (#264D3D) and generous open space for a simple silhouette. Its structure is intended to be distinct from Meta Threads.

The wordmark remains live text in the Flutter interface. The standalone symbol is shared by the shop, inventory app and launcher icons.

Android adaptive and round launcher resources use the original generated PNG with a cream background and inset foreground. Android 13 themed icons use its alpha silhouette. Legacy launchers use the same mark. Reference: https://developer.android.com/codelabs/basic-android-kotlin-compose-training-change-app-icon

Website identity: marysfashion. Editorial serif wordmark, forest green accents, coordinated catalogue and footer. The user-selected looping thread mark is retained. No domain has been registered.
